# Pigeon

Downloads for Pigeon, an internal API client. No source code lives here.

**Latest version:** https://github.com/smudham/pigeon-releases/releases/latest

- **macOS (Apple Silicon):** download the `.dmg`, drag Pigeon to Applications, then right-click → **Open** the first time.
- **Windows (x64):** run the `-setup.exe`; if SmartScreen warns, choose **More info → Run anyway**.

Installed apps update themselves from this repo (`appcast.xml` on macOS, each release's `latest.yml` on Windows).
